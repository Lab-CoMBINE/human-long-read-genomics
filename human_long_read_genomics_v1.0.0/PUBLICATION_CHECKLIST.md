# Before making the repository public

- [ ] Confirm the GitHub organization and repository slug; activate Pages from `main` / `docs`.
- [ ] Review each tool primary-publication association and repository/documentation link.
- [ ] Decide and add software and data licenses with the appropriate rights holders.
- [ ] Insert the final manuscript citation, journal and DOI when available.
- [ ] Compare methylation concordance summary values against the final manuscript.
- [ ] Check that benchmark table metrics match the final figures and supplemental tables.
- [ ] Verify Pages rendering and navigation on the actual public project URL.
- [ ] Audit the source data and metadata for paths, identifiers and other unintended disclosures.
- [ ] Add verified end-to-end reproduction scripts only after testing.
